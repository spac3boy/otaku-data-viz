# Pokémon dataset changelog

## 1.0.0 — 2026-08-10

- Adopted the existing May 25, 2026 static snapshot as the canonical v1 dataset.
- Preserved all 1,025 records and the existing public JSON schema to avoid changing the live visualization.
- Added explicit source, methodology, transformation, limitation, modeled-field, review, and reuse metadata.
- Added a JSON Schema document and dependency-free integrity validation.
- Established byte-identical publication from the canonical snapshot to the public site asset.

This governance release changes how the dataset is maintained and verified; it does not claim that the underlying Pokémon records were refreshed on August 10, 2026.
