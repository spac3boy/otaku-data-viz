What Is the Rarest Pokémon Type?

Ice is the least common type when a species counts in either its primary or secondary slot. Flying is the smallest group when each species is assigned only to its primary type. Both answers come from the same 1,025-species snapshot—the counting rule is what changes.

Direct answer

Ice is rarest overall; Flying is rarest as a primary type

Ice appears on 48 of the 1,025 species when both type slots count, fewer than any other type. If every species is grouped only by its primary type, Flying is rarest with nine species. These totals use each species' default variety and cover National Pokédex numbers 1 through 1025.

Why there are two valid answers

The either-slot count asks how many species have a type at all. A dual-type species contributes once to each of its two categories, which makes Ice the rarest type with 48 appearances.

The primary-type count assigns every species to exactly one group using the first type on its default variety. Under that rule, Flying is rarest with nine species. The two measures answer different questions, so a type-rarity claim should always state which one it uses.

Why Flying changes rank so dramatically

Flying appears on 109 species in either slot, making it the fourth-most common type by overall coverage. It is the primary type for only nine species in this snapshot because it appears far more often as a secondary type.

That 100-species difference is the largest contrast between the two columns. A primary-only treemap is useful for assigning every species to one category, but it should not be read as the total number of species associated with each type.

How uncommon Ice is in this snapshot

Ice appears on 48 species, or 4.7% of the 1,025-species dataset. Fairy is next with 64 appearances, leaving a gap of 16 species between the two least-common either-slot groups.

Ice is not the smallest primary group: 31 species use Ice as their primary type, compared with 29 for Fairy and nine for Flying. This is another reason the full counting method matters more than an unqualified rarity label.

What this snapshot covers

The dataset contains one record for each species from Bulbasaur through Pecharunt, National Pokédex numbers 1–1025, spanning Generations I–IX. It uses the default variety for each species.

The page is tied to dataset version 1.0.0 because later species or reviewed type changes can alter the ranking. Alternate forms, regional forms, Mega Evolutions, and other non-default varieties are outside this result.

Methodology & Sources

Dataset 1.0.0 · Reviewed 2026-08-10

Counts are recomputed from the 1,025 unique species records in the canonical Pokémon Species Treemap Dataset. The either-slot calculation counts each species once for every distinct type in its types array. The primary calculation counts only primaryType. Percentages divide either-slot counts by 1,025 and round to one decimal place.

  • PokéAPI v2 documentation — Documentation for the primary upstream species, Pokémon, type, generation, and evolution resources used by the canonical dataset generator.
  • PokéAPI source repository — Upstream project source and provenance context for the API-backed snapshot.

Limitations

  • The snapshot ends at National Pokédex #1025 and does not automatically include later announced or numbered species.
  • Only each species' default variety is counted; alternate, regional, Mega, Gigantamax, and other forms are not separate records.
  • Type assignments follow the default variety represented by the upstream snapshot and may differ for alternate forms.
  • The result measures species abundance by type, not competitive usage, encounter frequency, popularity, or type strength.

Questions & Answers

What is the rarest Pokémon type?

Ice is the rarest when a type counts in either the primary or secondary slot, appearing on 48 of 1,025 species. Flying is rarest when species are grouped only by primary type, with nine.

Why is Flying not rare when secondary types count?

Flying appears on 109 species overall but is the primary type for only nine. It is frequently paired as the second type, producing very different either-slot and primary-only rankings.

What is the second-rarest Pokémon type?

Fairy is the second-rarest by either-slot coverage with 64 species. Under primary-only grouping, Fairy is second-smallest with 29 species.

Are alternate Pokémon forms included?

No. The snapshot contains one record per National Pokédex species and uses its default variety. Alternate and regional forms are not separate records.

Will the rarest type ever change?

It can. This answer is tied to dataset version 1.0.0 and National Pokédex #1–1025. Later species additions or reviewed type assignments can change the counts.
